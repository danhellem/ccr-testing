# Shopping Cart

A shopping cart demo built with React, TypeScript, and Vite. Browse products by
category, manage your cart and wishlist, and switch between light and dark themes.

## Getting started

Install Node.js and npm, then run:

```sh
npm ci
npm run dev
```

Open the local URL printed by Vite in your browser.

## Development commands

| Command | Description |
| --- | --- |
| `npm run dev` | Start the development server. |
| `npm run typecheck` | Check TypeScript types without generating files. |
| `npm run build` | Check types and create a production build in `dist`. |
| `npm run preview` | Preview the production build locally after building. |

## Contributing

Keep changes focused and describe them clearly in your pull request. Run
`npm run typecheck` and `npm run build` before submitting code changes.
